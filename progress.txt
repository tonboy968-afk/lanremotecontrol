## Codebase Patterns
- Project uses markdown documentation for architecture and design specs in the docs/ directory
- Host service code goes in src-host/, client application code goes in src-client/
- Screen capture uses OS-specific native APIs (DXGI on Windows, ScreenCaptureKit on macOS) to minimize overhead
- Delta frame detection uses tile-based partitioning and hash-based change detection with a threshold-based full frame fallback (>30% tiles changed)
- Adaptive switching between LZ4 raw delta and low-delay H.264/AV1 is based on network RTT, packet loss, CPU/GPU utilization, and content type detection
- Input capture uses OS-specific low-level APIs (WH_KEYBOARD_LL/WH_MOUSE_LL on Windows, CGEventTap on macOS, evdev/X11 on Linux)
- Host input injection via SendInput requires proper foreground focus handling; modifier key state synchronization is critical to prevent stuck keys due to UDP packet loss
- Input events are serialized with type, high-resolution timestamp, and sequence numbers; host applies coalescing for rapid mouse movements and maintains key state maps to handle UDP unordered/duplicated packets
